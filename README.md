# Bakso Simulator: Kindness For A Better World

Game sederhana tentang penjual bakso menggunakan Python Arcade.

## 📁 Struktur Project

```
Algo-Cp/
├── assets/                 # Semua asset game
│   ├── images/            # Gambar-gambar
│   │   ├── characters/    # 👤 Karakter (penjual, pelanggan)
│   │   ├── items/         # 🍜 Item (bakso, mie, mangkok, dll)
│   │   ├── backgrounds/   # 🏞️ Background (gerobak, jalan, dll)
│   │   └── ui/           # 🖼️ UI elements (button, panel, dll)
│   ├── sounds/           # Audio
│   │   ├── music/        # Background music
│   │   └── effects/      # Sound effects
│   └── fonts/            # Font files
├── src/                  # Source code
│   ├── scenes/          # Game scenes
│   └── utils/           # Utility functions
├── main.py              # Entry point game
├── config.py            # Konfigurasi game
└── requirements.txt     # Dependencies
```

## 🚀 Cara Menjalankan

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Jalankan Game
```bash
python main.py
```

## 📸 Menyimpan Gambar

Simpan semua gambar Anda di folder `assets/images/` sesuai kategori:
- **Character** → `assets/images/characters/`
- **Item** → `assets/images/items/`
- **Background** → `assets/images/backgrounds/`
- **UI** → `assets/images/ui/`

Lihat `assets/images/README.md` untuk panduan lengkap.

## 🛠️ Teknologi
